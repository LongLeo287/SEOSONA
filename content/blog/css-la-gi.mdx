Nếu bạn đã từng nghe về việc thiết kế trang web, chắc hẳn bạn đã thấy thuật ngữ CSS xuất hiện nhiều lần. Nhưng CSS là gì, và nó hoạt động như thế nào?

## CSS là gì?

CSS (Cascading Style Sheets) là một ngôn ngữ dùng để thiết kế giao diện website.

Bạn có thể hiểu đơn giản là, nếu HTML là bộ xương của một trang web, thì CSS chính là quần áo và trang trí giúp trang web trông đẹp mắt hơn.

## Vai trò cùa CSS là gì?

CSS giúp bạn:

-   Thay đổi màu sắc, kiểu chữ, kích thước chữ
-   Căn chỉnh bố cục, đặt hình nền
-   Tạo hiệu ứng, chuyển động
-   Thiết kế trang web thân thiện với điện thoại

Ví dụ, nếu bạn muốn chữ trên trang web có màu đỏ, bạn có thể viết CSS như sau:

p {  
color: red;  
}

Điều này có nghĩa là tất cả đoạn văn (p) trên trang web sẽ hiển thị màu đỏ.

## CSS hoạt động như thế nào?

Để CSS có thể hoạt động trên website bạn cần nhúng vào website bằng 3 cách sau đây:

-   Inline CSS: Viết trực tiếp vào thẻ HTML.

Ví dụ:

<p style=”color: blue;”>Chữ này màu xanh</p>

-   Internal CSS: Viết trong phần <style> của trang web.

Ví dụ:

<style>  
p { color: green; }  
</style>

-   External CSS: Viết trong một tệp riêng, sau đó liên kết với trang HTML.

<link rel=”stylesheet” href=”styles.css”>

Trong tệp styles.css bạn có thể viết:

p { color: purple; }

## Kết luận

CSS giúp trang web đẹp hơn, dễ đọc hơn và có trải nghiệm tốt hơn. Nếu bạn muốn làm web chuyên nghiệp, hãy bắt đầu học CSS ngay từ bây giờ!
