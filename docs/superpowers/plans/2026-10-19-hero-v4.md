# Hero v4 implementation plan

## Scope

Implement the approved 2.5D Hero-to-CoreSolutions redesign in the existing homepage architecture. The implementation is intentionally dependency-free beyond current PixiJS, Anime.js and Morphicons packages.

## Tasks

1. Add a regression contract to `scripts/audit-browser.mjs` for the shared StrategyCore, section-top handoff anchor, single transition visual and title distance.
2. Add `components/hero/StrategyCore.tsx` as the reusable decorative focal-point layer with a forwarded HTML ref.
3. Update `components/sections/Hero.tsx` to use StrategyCore, shorten the scroll stage, and keep the existing semantic HeroContent and link nodes.
4. Update `components/hero/useHeroTransitionMetrics.ts` to measure the new handoff anchor first and retain a safe compatibility fallback.
5. Update `components/hero/hero-motion.ts` and `components/hero/useHeroMotion.ts` for the shorter Hero and later label handoff without creating a new scheduler.
6. Consolidate `components/sections/CoreSolutions.tsx` to one top transition ribbon, earlier readable title/grid reveal, and no duplicate inner arc.
7. Tune `components/hero/HeroScene.tsx` and `HeroFallback.tsx` so the decorative arc yields completely to the section ribbon during handoff.
8. Run focused red/green browser audit, then lint, typecheck, build, browser audit, performance audit and diff checks.
9. Inspect generated screenshots at desktop, tablet and mobile widths and repair only confirmed regressions.

## Verification commands

```text
npm run lint
npm run typecheck
npm run build
$env:SEOSONA_BASE_URL='http://localhost:<port>'; npm run audit:browser
npm run audit:performance
git diff --check
```

## Rollback

Revert only the files listed in this plan if the focused audit cannot be made green. Do not reset, clean, or overwrite the user's unrelated worktree changes.
